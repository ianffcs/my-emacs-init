`ian/clipboard-adapter`, evaluated per call, returns one of the symbols: `wsl`, `gui`, `wayland`, `x11`, or nil. Priority: wsl > gui > wayland > x11 > nil. `ian/clipboard-copy` and `ian/clipboard-paste` are set unconditionally as interprogram-cut-function and interprogram-paste-function. The clipboard refactor fixed a bug where GUI frames outside WSL had no working clipboard because interprogram-cut-function was set to a tty-only function at load time.
