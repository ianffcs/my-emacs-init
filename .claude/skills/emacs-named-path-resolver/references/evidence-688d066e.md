`core-settings.el` now owns the named Org files. Added `ian/org-files`, a defvar alist of inbox, todo, notes, diary and elfeed. Added `(ian/org-file NAME)`, which resolves with `expand-file-name` against `org-directory` at call time and signals `error "Unknown Org file: %S"` for an unknown name. Each consumer (ui-dashboard.el, core-editor.el, tool-mcp.el, tool-comm.el) updated to call `(ian/org-file 'inbox)` etc., eliminating duplicate path computations.
